快速开始

启动服务 → 配置模型 → 开始对话，三步进入工作状态

  1. 启动服务 双击安装目录中的 start.bat，等待控制台出现 Started MateClawApplication in X.XX seconds 即启动成功。
  2. 访问系统 打开 Chrome 或 Edge 浏览器，访问 http://localhost:18088，使用默认账号登录：
    用户名admin
    密码admin123
  3. 配置 AI 模型 登录后进入侧边栏 设置 → 模型管理，点击要使用的模型提供商卡片，填入 API Key 并保存。系统会自动探测连接可用性。
    推荐
    首次使用建议选择通义千问（DashScope），注册后有免费额度；也支持 OpenAI、DeepSeek、Anthropic 等主流模型。

配置完成后，点击左侧的 「对话」 进入聊天界面，选择一个数字员工开始交流。

场景一：数字员工

招聘、训练、管理你的 AI 员工

核心认知

一个数字员工 = 模型（大脑） + 技能（工作手册） + 工具（原子能力） + 提示词（工作守则） + 记忆（长期经验）

把它当成一个你刚招来的新员工：你需要告诉它岗位是什么、该怎么做事、能用哪些工具、以前学到了什么。配置得越精确，它干活越靠谱。

创建数字员工

  1. 进入员工管理 侧边栏 → 数字员工，点击 「新员工」 按钮。
  2. 选择岗位模板（可选） 系统提供预置岗位模板（如翻译专家、写作助手、客服等），选一个可以快速上手。也可以点 「从空白开始」。
  3. 填写基本信息
    字段说明示例
    名称员工名字数据分析师小王
    岗位（Role）一句话职业身份数据分析师
    目标（Goal）它存在的理由把数据变成可执行的业务洞察
    背景（Backstory）经验和原则（用户看不见但每次对话都能感受到）在数据领域工作十年，信奉先问对问题再写 SQL
    类型ReAct（工具调用）或 Plan-and-ExecuteReAct
    模型留空跟随全局默认，也可单独指定qwen-max
  4. 绑定技能和工具 切换到 「技能」 和 「工具」 标签页，勾选该员工可使用的技能和工具。留空则使用所有已启用的技能/工具。
  5. 保存并开始对话 保存后在员工卡片上点击 「对话」，即可开始聊天。

与员工对话

在 「对话」 页面：

  • 左上角下拉切换不同的数字员工
  • 输入消息后按 Enter 发送，Shift+Enter 换行
  • 支持拖拽上传文件（图片、PDF、文档等），员工会自动处理
  • 点击消息气泡上的朗读按钮可以让 AI 语音朗读回答
  • 开启 「深度思考」 开关可让模型进行更深入的推理

查看员工状态

侧边栏 → 员工状态，可以实时看到哪些员工正在工作、是否卡住、运行了多久。支持一键停止或强制结束。

技巧
先在对话里跑通一个完整流程，确认员工能胜任后，再把同样的输入配置成定时任务或接入 IM 渠道——这是最稳的上线方式。

场景二：Wiki 知识库

上传原始材料，AI 自动消化为结构化知识页面

核心认知

知识库不是简单的"文档搜索"。它的工作流程是：原始材料 → AI 消化 → 生成 Wiki 页面 → 建立知识图谱 → 注入 Agent 上下文。Agent 回答问题时会自动从知识库中检索相关页面。

完整工作流

创建知识库→ 上传材料→ AI 生成页面→ 知识图谱→ 绑定 Agent

创建知识库

  1. 新建知识库 侧边栏 → Wiki 知识库，点击 「新建知识库」，输入名称和描述。
  2. 上传原始材料 进入知识库后切换到 「原始材料」 标签页。支持的方式：
    • 拖拽上传文件：PDF、Word、Excel、TXT、Markdown 等
    • 添加文本：手动粘贴内容
    • 扫描本地目录：输入目录路径批量导入
  3. 等待 AI 处理 上传后系统自动开始处理。处理过程包括：
    分析内容→ 生成 Wiki 页面→ 添加交叉链接→ 向量化索引
    处理状态会实时显示在材料旁边。
  4. 查看和编辑页面 切换到 「Wiki 页面」 标签页，可以看到 AI 生成的所有知识页面。点击任意页面查看详情，支持手动编辑和补充。

知识图谱

切换到 「知识图谱」 标签页，可以看到所有页面之间的关联关系可视化。关联类型包括：

关联类型含义
直接引用页面间有明确的文字链接
共享片段两个页面引用了同一段原始内容
共享来源两个页面来自同一份原始材料
语义相近通过向量相似度发现的隐含关联

加工器（Transformations）

加工器是可复用的提示词模板，针对每份原始材料执行自定义分析。例如创建一个"合同风险点提取"加工器，自动对每份上传的合同文档进行风险分析。

进入知识库 → 「加工器」 标签页 → 「新建加工器」，配置提示词模板（可用 {input_text} 和 {title} 占位符），开启「默认运行」后，新材料处理完成会自动触发。

绑定到 Agent

知识库创建完成后，在数字员工的 「技能」 标签页中，可以看到与知识库相关的 Wiki 工具（如 wiki_search_pages、wiki_read_page 等）。Agent 在对话中会自动调用这些工具来检索知识库中的内容。

近况快照（Hot Cache）
知识库支持自动生成"近况快照"——一段滚动更新的摘要，会被注入到 Agent 的系统提示中。这意味着 Agent 每次对话不必重新检索就能了解知识库最近发生了什么。在 「近况快照」 标签页中可以查看和手动重建。

场景三：技能创建与管理

为数字员工编写工作手册（SKILL.md）

核心认知

技能 ≠ 工具。工具是一次性的原子操作（如"搜索网页"、"读取文件"），技能是一整套工作手册，教会 Agent 按流程完成一件复杂的事。技能内部可以声明需要哪些工具。

创建技能的三种方式

方式一：使用模板向导（推荐新手）

  1. 进入模板库 侧边栏 → 技能 → 右上角 「模板库」，或直接访问 /skills/templates。
  2. 选择模板 浏览预置模板（如 Claude Code 助手、Obsidian 笔记等），点击 「使用模板」。
  3. 填写参数并安装 按提示填写模板参数 → 预览生成的 SKILL.md → 点击 「安装 Skill」。

方式二：通过对话创建（AI 辅助）

在对话中找到 「技能创作者」（Skill Builder）这个数字员工，用自然语言描述你需要的技能，它会自动生成 SKILL.md 并安装。

方式三：手动创建

  1. 新建技能 侧边栏 → 技能 → 点击 「新建技能」，填写名称和描述。
  2. 编辑 SKILL.md 在技能详情面板的 「正文」 标签页中，编写 SKILL.md 内容。

SKILL.md 结构说明

---
name: my-skill
version: 1.0.0
description: 这个技能做什么
author: your-name
icon: 🛠️
allowed-tools:
  - search
  - read_file
  - execute_shell_command
---

# 技能名称

## 触发条件
当用户要求 XXX 时触发此技能。

## 执行流程
1. 第一步：分析用户需求
2. 第二步：调用工具获取数据
3. 第三步：整理输出结果

## 输出格式
- 使用 Markdown 格式
- 包含标题和要点列表

技能文件存储位置

~/.qingwenclaws/skills/ ← 技能根目录
  my-skill/
    SKILL.md ← 技能主文件（必须）
    LESSONS.md ← AI 自动积累的经验（自动生成）
    scripts/ ← 可选的脚本文件
    references/ ← 可选的参考资料
  another-skill/
    SKILL.md

在 Windows 环境下，完整路径为：C:\Users\你的用户名\.qingwenclaws\skills\

绑定技能到员工

进入 数字员工 → 编辑 → 技能标签页，搜索并勾选需要绑定的技能。绑定后，该员工的 LLM 提示词中会自动注入技能内容。

经验自进化（LESSONS.md）

每个技能会自动积累使用经验。当 Agent 在使用技能过程中发现有用的模式或踩了坑，它会自动记录到 LESSONS.md 中。下次使用同一技能时，这些经验会被注入到提示词中，让 Agent 越用越熟练。

在技能详情面板的 「经验」 标签页中可以查看和管理经验。

技巧
在对话中告诉 Agent「请把这条经验记录到 XX 技能下」，即可手动触发经验记录。

场景四：记忆功能

让数字员工越用越懂你

核心认知

记忆是数字员工的"长期大脑"。没有记忆的 Agent 每次对话都从零开始；有了记忆，Agent 会记住你的偏好、你的项目上下文、上次没做完的事，让对话越来越流畅。

四种记忆文件

文件名作用谁来维护
AGENTS.md角色定义 — Agent 是谁、核心原则与边界人工 + AI
PROFILE.md用户画像 — Agent 对你的了解（职业、偏好等）AI 自动抽取
SOUL.md灵魂档案 — Agent 的信念、做事风格、深层性格人工设定
MEMORY.md日常记忆 — 事实、偏好、项目上下文、待办AI 自动 + 人工编辑

查看和编辑记忆

  1. 进入记忆页面 侧边栏 → 记忆，在顶部下拉选择要查看的智能体。
  2. 浏览记忆内容
    • 长期记忆 标签页：查看 MEMORY.md、PROFILE.md、SOUL.md 等文件的内容概览
    • 整理时间线 标签页：查看记忆的整理历史（包括夜间自动整理和手动专题整理）
    • 事实库 标签页：查看从对话中抽取的结构化事实
  3. 手动编辑 侧边栏 → 设置 → 智能体上下文，选择智能体后可以直接编辑任意 .md 文件的内容。

记忆文件存储位置

记忆文件以工作区为维度组织，存储在数据库中，可通过以下两个入口管理：

  • 记忆页面（侧边栏 → 记忆）：可视化浏览和概览
  • 智能体上下文（设置 → 智能体上下文）：Markdown 编辑器，直接编辑内容

自动记忆抽取

在对话过程中，Agent 会自动识别值得记住的信息并写入 MEMORY.md。例如：

  • 你提到的个人偏好（"我喜欢简洁的报告风格"）
  • 项目关键信息（"我们的数据库用的是 PostgreSQL 14"）
  • 待办事项（"下周一前完成数据迁移"）

夜间巩固（Dreaming）

系统会定期自动整理记忆，包括：

  • 去重：合并重复的记忆条目
  • 清理：移除过期或不再相关的内容
  • 整合：将零散的信息归纳成结构化条目

整理结果可以在 「整理时间线」 中查看回顾。

专题整理

除了自动整理，你也可以手动触发专题整理：在记忆页面切换到 「整理时间线」 标签页，输入主题（如"项目架构"），点击 「开始整理」，Agent 会围绕该主题重新组织记忆。

技巧
在对话中直接告诉 Agent："记住我平时不吃香菜""以后报告用英文"，它会自动将这些偏好写入 MEMORY.md。如果发现 Agent 记错了什么，去「设置 → 智能体上下文」手动修正。

场景五：定时任务

让数字员工按时自动执行工作

核心认知

定时任务的本质 = 到点了，系统自动给员工发一条消息。触发后，员工照常走完整个对话流程（思考 → 调用工具 → 生成回答）。所以先在对话里跑通一遍，再设定时任务，最省心。

创建定时任务

  1. 进入定时任务页面 侧边栏 → 定时任务，点击 「新建任务」。
  2. 基本配置
    字段说明
    任务名称给任务起个名字，便于识别
    关联 Agent选择哪个数字员工来执行
    任务类型文字消息 / 提醒 / Agent 目标
  3. 设置触发消息
    • 文字消息：相当于到时间自动给 Agent 发送这条消息，Agent 会正常处理并生成回答
    • 提醒：到点原样推送内容，不经过 LLM 改写
    • Agent 目标：直接描述 Agent 要完成的目标
  4. 设置执行频率
    频率说明示例
    每小时每小时的指定分钟执行每小时第 30 分钟
    每天每天固定时间执行每天 9:00
    每周指定星期几和时间执行每周一至周五 9:00
    自定义使用 Cron 表达式0 9 * * 1-5
  5. 保存并启用 勾选 「立即启用」 并保存。也可以先创建后手动启用。

Cron 表达式速查

┌──── 分钟 (0-59)
│ ┌──── 小时 (0-23)
│ │ ┌──── 日 (1-31)
│ │ │ ┌──── 月 (1-12)
│ │ │ │ ┌──── 星期 (0-7, 0和7都是周日)
│ │ │ │ │
* * * * *

常用示例：
0 9 * * *       每天 9:00
0 9 * * 1-5     工作日 9:00
0 */2 * * *     每 2 小时
30 8 1 * *      每月 1 号 8:30
0 9,18 * * *    每天 9:00 和 18:00

管理任务

  • 立即执行：在任务列表点击「立即执行」，不必等到下次触发时间
  • 启用/停用：通过开关随时控制任务状态
  • 查看执行结果：执行后在 「对话」 页面可以找到以 cron_ 开头的自动对话
注意
定时任务触发后等价于"有人发了一条消息"，员工照常完成对话流程。多实例部署场景下有分布式锁保护，同一任务只会执行一次。

场景六：数据分析专家

上传 Excel 或连接数据库，用自然语言做数据分析

核心认知

数据分析专家让你用说话代替写 SQL。你只需要把数据准备好（上传 Excel 或连接数据库），然后用自然语言提问，Agent 会自动生成查询、执行分析、输出结果。

两种数据接入方式

方式一：上传 Excel 文件

  1. 创建数据集模板 侧边栏 → 数据分析 → 数据集模板 → 「新建模板」。手动定义字段，或直接 「从 Excel 导入」 自动识别字段结构。
    推荐
    使用"从 Excel 导入"方式——上传一份示例 Excel，系统会自动解析列名、类型，一键生成模板。
  2. 配置字段语义 在模板的字段管理中，为每个字段填写 「语义」 描述。这段文字会告诉数据分析专家这一列的业务含义，是准确分析的关键。
    字段属性说明
    角色维度（分组字段）/ 度量（计算字段）/ 时间键
    聚合方式SUM / AVG / COUNT / MAX / MIN 等
    时间粒度日 / 周 / 月 / 季 / 年
    语义业务含义说明（如"客户下单金额，单位：元"）
  3. 创建数据集并上传数据 数据集 → 「新建数据集」，选择刚才的模板，然后点击 「上传 Excel」 上传 .xlsx 文件。
  4. 开始分析 在数据集页面点击 「分析」，进入与数据分析专家的对话界面。

方式二：连接外部数据库

  1. 添加数据源 数据分析 → 外部数据源 → 「添加数据源」。
  2. 填写连接信息
    字段说明
    数据库类型MySQL / PostgreSQL / ClickHouse 等
    主机和端口数据库服务器地址
    数据库名要连接的数据库
    用户名 / 密码数据库凭证
  3. 测试连接 点击 「测试连接」，显示"连接成功"后保存。
  4. 在对话中使用 与绑定了 query_datasource 工具的数字员工对话，它会自动根据你的问题生成 SQL 查询并执行。

提问示例

自然语言提问Agent 会做什么
"上个月销售额最高的前 10 个产品是什么？"生成 SQL 查询 → 执行 → 返回排名表格
"按月统计今年的客户增长趋势"聚合查询 → 返回月度数据
"对比 Q1 和 Q2 各区域的业绩"多维交叉查询 → 对比分析
"这份数据里有没有异常值？"统计分析 → 识别离群点
技巧
字段的「语义」描述越精准，分析结果越准确。比如同样是"金额"字段，写上"客户订单金额（含税），单位：人民币元"比空着好得多。

心智模型：把平台当成一家公司

理解各模块之间的关系

SurveyMind 的设计哲学可以类比为经营一家公司：

公司类比平台对应你要做的
招聘员工 创建数字员工 定义岗位、职责、工作原则
培训手册 编写 Skill（技能） 写好 SOP 流程，员工照手册执行
公司知识库 Wiki 知识库 把文档、资料上传，让员工能查阅
员工笔记本 记忆系统 员工自己记录工作经验和用户偏好
排班表 定时任务 安排员工每天几点做什么事
数据分析部门 数据分析专家 把数据给他，用说话代替写 SQL
办公工具 工具（Tools） 搜索引擎、文件处理、生成图表等原子能力
安保部门 安全（工具防护 + 审批流） 设置哪些操作需要审批、哪些工具禁止使用

推荐上手路径

1. 配模型→ 2. 建员工→ 3. 对话跑通→ 4. 建知识库→ 5. 写技能→ 6. 设定时任务
核心原则

先跑通再自动化：在对话中手动验证 Agent 能完成任务后，再配置定时任务或接入 IM 渠道。

先粗后细：从预置模板和内置技能开始，等理解了系统能力后再写自定义 Skill。

喂数据就是喂能力：知识库内容越丰富、字段语义越清晰，Agent 的回答越准确。
