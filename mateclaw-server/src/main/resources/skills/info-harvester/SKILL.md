# 信息采集 · 每日简报

每日定时或按需触发，从下表 4 个权威站点拉取**近 24 小时**的新发布内容，去重后产出一份《每日要情简报》。

## 抓取来源（外网，固定不变）

| # | 站点 | 列表页 URL | 关注栏目 |
|---|------|-----------|----------|
| 1 | 农业农村部 · 政策法规 | http://www.moa.gov.cn/gk/zcfg/ | 部令、规章、政策性文件 |
| 2 | 农业农村部 · 政务动态 | http://www.moa.gov.cn/xw/zwdt/ | 部委动态 |
| 3 | 河南省农业农村厅 | https://nynct.henan.gov.cn/ | 首页要闻、通知公告 |
| 4 | 河南省发改委 | https://fgw.henan.gov.cn/ | 首页通知公告 |
| 5 | 河南省人民政府 · 政务公开 | https://www.henan.gov.cn/zwgk/ | 政务动态、文件 |

> 内网来源待补，确认后追加到本表即可。

## 工作流程

### 第 1 步：依次抓取列表页链接

对上表每条 URL 调用：

```
web_fetch(url="<列表页URL>", mode="links")
```

`mode=links` 会返回 `标题<TAB>绝对URL`，每行一条。

### 第 2 步：本地筛选当日条目

- 标题里包含日期字样的：留下今天或昨天的（昨天兜底，避免凌晨爬取漏掉）
- 标题里没有日期的：留下前 10 条（列表页通常按发布时间倒序）
- 过滤明显的导航/页脚链接（标题含「首页 / 关于 / 联系 / 版权 / 友情」等）

### 第 3 步：按需深读正文

对每条候选链接调用：

```
web_fetch(url="<详情页URL>", mode="text")
```

只读**最多 8 条**正文（控制成本与时延）。读完后用 2~3 句话提炼要点。

### 第 4 步：生成简报

严格按以下 Markdown 结构输出（中文，简短直接）：

```markdown
# 每日要情简报 · YYYY-MM-DD

## 一、国家政策（农业农村部）
- **<标题>** — <2~3 句要点>
  来源：农业农村部 · <yyyy-MM-dd> · <原文链接>

## 二、河南省级动态
### 河南省农业农村厅
- ...
### 河南省发改委
- ...
### 河南省人民政府
- ...

## 三、值得关注
<编辑视角，1~3 条跨源关联或趋势判断；没有就写「无」>

## 四、采集统计
- 共扫描 N 个列表页，命中 M 条候选，深读 K 条
- 失败/超时来源：<列出 host，没有就写「无」>
```

### 第 5 步：失败容错

- 单个 URL 失败不要中止整体流程；在「四、采集统计」里记 host
- 全部 5 个 URL 都失败时，回复一句中文错误说明并停止
- 不要伪造没抓到的内容，宁可在对应小节写「今日无新内容」

## 注意事项

- **只抓上表 5 个 URL**，不要被详情页里的链接带走，不要联想其他站点
- web_fetch 已经做了 per-host 1.5 s 节流，连续调用不会触发反爬，**但**也不要并发同站
- 简报正文中**禁止**编造数据，所有引用必须能在抓取结果里找到原文
- 标题/摘要保留原文用词，不要主观解读政策含义；解读放到「值得关注」一节并标注「编辑视角」
- 单次产出控制在 800~1500 字，过长用户不读
